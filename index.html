Why it exists

Monitoring without the overhead

Most monitors bring a database, a UI, a config server, and a subscription. nexus-agent is one binary you point at a JSON file.

⚡

Concurrent checks

Every service is checked in parallel. 79 endpoints complete in roughly 25ms — the slowest service sets the total time, not the sum.

🔔

State-change alerts

Slack messages fire only when a service goes down or comes back. A service staying down does not re-alert, so no alert fatigue.

🌐

TCP and UDP

Works for HTTP services, DNS resolvers, databases, message brokers, or anything else that listens on a port.

👁

Watch or one-shot

Run once for a cron job, or run in continuous watch mode with a configurable interval.

Install

One curl, one chmod, done

Pre-built binaries for Linux, macOS, and Windows — all cross-compiled and checksummed on each release.

linux · amd64
curl -L https://github.com/Humbulan/nexus-agent/releases/latest/download/nexus-agent-linux-amd64 -o nexus-agent
chmod +x nexus-agent
sudo mv nexus-agent /usr/local/bin/
macOS · Apple Silicon
curl -L https://github.com/Humbulan/nexus-agent/releases/latest/download/nexus-agent-darwin-arm64 -o nexus-agent
chmod +x nexus-agent
sudo mv nexus-agent /usr/local/bin/
docker · ghcr.io
docker run --rm -v $(pwd)/services.json:/services.json \
  -e NEXUS_SLACK_WEBHOOK="https://hooks.slack.com/services/..." \
  ghcr.io/humbulan/nexus-agent --watch --config /services.json
Usage

Point it at a JSON file

Two commands cover almost every use case. Add a Slack webhook environment variable to turn on alerts.

services.json
[
  {"name": "HTTP_Server", "port": "4221", "protocol": "tcp"},
  {"name": "DNS_Server",  "port": "2053", "protocol": "udp"},
  {"name": "Redis",       "port": "6380", "protocol": "tcp"}
]
terminal
# One-shot check
nexus-agent --config services.json

# Continuous watch (default 30s)
nexus-agent --watch --config services.json

# Custom interval
nexus-agent --watch --interval 10s

# Enable Slack alerts
export NEXUS_SLACK_WEBHOOK="https://hooks.slack.com/services/..."
